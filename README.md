# Notas de programador

programa creado para que usuarios puedan crear sus propias "notas" que funcionen con snipsets de fragmentos de código recurrentes para compiar y utilizar más adelante.

La idea surgió después de utilizar distintas queries SQL recurrentemente en otro proyecto personal, para tareas de análisis. Estas consultas no tenían un papel importante dentro de un *pipeline* así que solo eran con fines de investigación. Preferí tenerlas guardadas en un lugar sin que importe mucho si se pierden o no.

Estoy seguro de que a ti también te ayudaría tener algo así, es por eso que decidí hacerlo publico como una herramienta que todos puedan probar :D
